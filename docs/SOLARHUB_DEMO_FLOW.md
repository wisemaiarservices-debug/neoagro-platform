# NeoAgro SolarHub Demo Flow

## Demo Scenario

A heatwave is forecast for an agrivoltaic site.

## Flow

1. NOVA Command Center shows site health.
2. Weather forecast indicates heatwave risk.
3. Soil moisture trends downward.
4. NeoAgro forecasts increased irrigation demand.
5. NeoGrid coordinates battery and pump timing.
6. NeoCell confirms gateway and sensor readiness.
7. NOVA Twin simulates baseline vs optimized scenario.
8. NOVA Intelligence recommends evening irrigation for operator approval.
9. Dashboard shows expected water savings, yield protection, energy impact, and carbon reduction.

## Core Message

NeoAgro is not a dashboard. It is the agriculture intelligence module inside NOVA OS.
